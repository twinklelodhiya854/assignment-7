Create a Flipkart discount calculator that asks the user for the total cart amount. Use nested if statements to check: if amount > 2000, apply 20% discount; else if amount > 1000, apply 10% discount; else, no discount. Print the final amount to pay.

Hint: Use nested ifs to check each discount slab. let amount = Number(prompt("Enter your total cart amount:")); let discount; let finalAmount; if (amount > 2000) { discount = amount * 0.20; if (amount > 2000) { finalAmount = amount - discount; } } else { if (amount > 1000) { discount = amount * 0.10; finalAmount = amount - discount; } else { discount = 0; finalAmount = amount; } } console.log("Final amount to pay: ₹" + finalAmount);
